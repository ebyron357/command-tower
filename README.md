# command-tower

**The central command platform for AI engineering, automation, knowledge, and project execution across the BWA ecosystem.**

## Claude Company Operating System

This repository includes a project-level Claude Code **Company OS**:

- Departments under `company/`
- Skills under `.claude/skills/`
- Subagents under `.claude/agents/`
- Commands under `.claude/commands/`
- Registries under `registries/`
- Governance docs at the repository root
- Validation: `python scripts/validate/validate_company_os.py`

Start with `CLAUDE.md`, `COMPANY_OS.md`, and `PROJECT_TRUTH.md`.
