# Product Department

Capabilities owned by this department:

- `skill.product-requirements` (skill) — Write PRDs with problem, users, requirements, non-goals, metrics.
- `skill.user-stories` (skill) — Create user stories with personas, flows, and acceptance hooks.
- `skill.acceptance-criteria` (skill) — Define crisp Given/When/Then and edge-case criteria.
- `skill.product-roadmap` (skill) — Build outcome-oriented roadmaps with sequencing and bets.
- `skill.product-prioritization` (skill) — Prioritize using RICE/WSJF/custom scoring with evidence.
- `skill.experiment-planning` (skill) — Design experiments with hypothesis, metrics, and stop rules.
- `skill.product-analytics-planning` (skill) — Define product analytics events and success metrics.
- `skill.release-planning` (skill) — Plan product releases with audiences, risks, and comms.
- `skill.product-review` (skill) — Review product artifacts against user value and feasibility.
- `agent.product-manager` (subagent) — Own requirements, prioritization, and acceptance clarity.
- `cmd.project-truth` (command) — Refresh PROJECT_TRUTH.md from verified repository evidence only.
