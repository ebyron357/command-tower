# Engineering Department

Capabilities owned by this department:

- `skill.repo-onboarding` (skill) — Onboard Claude and humans to an unfamiliar repository with architecture map and risks.
- `skill.technical-architecture` (skill) — Design or review system architecture with constraints, ADRs, and trade-offs.
- `skill.feature-implementation` (skill) — Implement features with tests, incremental commits plan, and verification.
- `skill.systematic-debugging` (skill) — Debug defects with hypothesis, evidence, isolation, and regression tests.
- `skill.safe-refactoring` (skill) — Refactor with characterization tests, small steps, and behavior preservation.
- `skill.code-review-skill` (skill) — Review diffs for correctness, security, maintainability, and missing tests.
- `skill.test-generation` (skill) — Generate meaningful unit/integration/e2e tests with failure cases.
- `skill.webapp-testing` (skill) — Plan and execute local webapp testing with reconnaissance then action.
- `skill.api-design` (skill) — Design APIs with contracts, versioning, errors, auth, and examples.
- `skill.database-design` (skill) — Design schemas, migrations, indexes, and data integrity rules.
- `skill.dependency-review` (skill) — Review dependencies for risk, license, pinning, and alternatives.
- `skill.devops-cicd` (skill) — Design CI/CD pipelines, environments, and release automation safely.
- `skill.release-engineering` (skill) — Plan releases with changelogs, rollback, and readiness checks.
- `skill.technical-documentation` (skill) — Write accurate technical docs from code and verified behavior.
- `agent.repository-auditor` (subagent) — Audit repository structure, docs, secrets risk, and onboarding readiness.
- `agent.software-architect` (subagent) — Produce architecture options, ADRs, and constraint analysis.
- `agent.implementation-engineer` (subagent) — Implement approved designs with tests and verification evidence.
- `agent.code-reviewer` (subagent) — Independent code review with severity-ordered findings.
- `cmd.repo-onboard` (command) — Run repository onboarding workflow and produce PROJECT_TRUTH updates.
- `cmd.architecture-review` (command) — Run architecture review against goals and constraints.
- `cmd.code-review` (command) — Run structured code review on current changes.
- `cmd.test-plan` (command) — Produce a test plan with risks and coverage targets.
- `cmd.run-validation` (command) — Execute Company OS validation suite and summarize results.
- `cmd.dependency-review` (command) — Review dependency changes and supply-chain risk.
- `cmd.verified-execution` (command) — Execute a change with explicit verification gates.
- `plugin.anthropic-agent-skills-marketplace` (plugin) — Official Anthropic agent skills marketplace reference.
- `plugin.obra-superpowers` (plugin) — SDLC methodology plugin (planning, TDD, debugging).
- `plugin.claude-mem` (plugin) — Persistent memory plugin with local worker.
- `mcp.context7` (mcp) — Up-to-date library documentation MCP.
- `mcp.mcp-builder-skill-ref` (mcp) — Anthropic MCP builder skill as reference for building MCP servers.
- `external.skill-creator` (external) — Anthropic skill creator for authoring/eval of skills.
- `external.anthropic-frontend-design` (external) — Official frontend design skill patterns.
- `external.anthropic-webapp-testing` (external) — Official webapp testing skill patterns.
