# Design Department

Capabilities owned by this department:

- `skill.ux-research` (skill) — Plan and synthesize UX research with methods and bias controls.
- `skill.ui-design` (skill) — Produce UI design direction with hierarchy, states, and specs.
- `skill.design-systems` (skill) — Extend or review design tokens, components, and usage rules.
- `skill.accessibility-review` (skill) — Review accessibility against WCAG-oriented checks.
- `skill.frontend-design` (skill) — Apply distinctive, brand-safe frontend design guidance.
- `skill.visual-quality-review` (skill) — Critique visual quality, hierarchy, and polish.
- `skill.prototype-planning` (skill) — Plan prototypes with fidelity, questions, and success signals.
- `skill.brand-application` (skill) — Apply brand rules to surfaces without diluting identity.
- `agent.design-director` (subagent) — Lead design quality, brand application, and UX coherence.
- `cmd.design-review` (command) — Run design and accessibility review workflow.
- `external.ui-ux-pro-max` (external) — Community UI/UX intelligence skill pack.
- `external.taste-skill` (external) — Community anti-slop frontend taste skill.
- `external.transitions-dev` (external) — CSS transition snippets and agent skill.
