# Data Analytics Department

Capabilities owned by this department:

- `skill.data-quality-analysis` (skill) — Assess data quality dimensions and remediation plan.
- `skill.kpi-design` (skill) — Design KPI trees with definitions and anti-gaming notes.
- `skill.metric-diagnostics` (skill) — Diagnose metric movements with decomposition.
- `skill.dashboard-planning` (skill) — Plan dashboards with audience, questions, and definitions.
- `skill.quantitative-analysis` (skill) — Perform structured quantitative analysis with assumptions.
- `skill.forecasting` (skill) — Build forecasts with scenarios and uncertainty ranges.
- `skill.analytics-report-generation` (skill) — Generate analytics reports with charts narrative and caveats.
- `skill.experiment-analysis` (skill) — Analyze experiments with validity threats and decisions.
- `agent.data-analyst` (subagent) — Analyze metrics, experiments, and data quality with explicit assumptions.
