# Finance Department

Capabilities owned by this department:

- `skill.budgeting` (skill) — Build budgets with drivers, assumptions, and variance framework.
- `skill.scenario-planning` (skill) — Create financial scenarios with sensitivities.
- `skill.unit-economics` (skill) — Analyze unit economics and contribution margins.
- `skill.cash-flow-analysis` (skill) — Analyze cash flow timing and runway risks.
- `skill.financial-reporting` (skill) — Prepare financial narrative reports with caveats.
- `skill.pricing-analysis` (skill) — Analyze pricing options with willingness-to-pay proxies.
- `skill.investment-evaluation` (skill) — Evaluate investments with ROI/NPV framing and risks.
- `skill.business-case` (skill) — Build business cases with options and decision ask.
- `agent.finance-analyst` (subagent) — Produce financial analyses with assumptions and disclaimers.
- `cmd.financial-analysis` (command) — Run financial analysis workflow with disclaimers.
