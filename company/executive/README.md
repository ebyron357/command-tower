# Executive Department

Capabilities owned by this department:

- `skill.strategic-planning` (skill) — Produce multi-horizon strategic plans with options, trade-offs, and decision criteria.
- `skill.decision-brief` (skill) — Create decision briefs with options, risks, recommendation, and ask.
- `skill.initiative-prioritization` (skill) — Rank initiatives using impact, effort, risk, and dependency scoring.
- `skill.status-aggregation` (skill) — Aggregate department statuses into an executive snapshot with blockers and risks.
- `skill.risk-escalation` (skill) — Identify, classify, and escalate cross-cutting risks with owners and mitigations.
- `skill.cross-department-coordination` (skill) — Coordinate work across departments with RACI, interfaces, and handoffs.
- `skill.completion-review` (skill) — Verify claimed completion against evidence gates and remaining work.
- `skill.executive-reporting` (skill) — Produce concise executive reports with outcomes, metrics, risks, and asks.
- `agent.chief-of-staff` (subagent) — Orchestrate routing, delegation, status aggregation, and completion review.
- `cmd.company-status` (command) — Produce current company OS status from PROJECT_TRUTH, STATUS, and registries.
- `cmd.company-plan` (command) — Create or refresh a cross-department plan with owners and milestones.
- `cmd.company-health` (command) — Assess operating health: registry consistency, validation, security, gaps.
- `cmd.completion-audit` (command) — Run completion gates against claimed deliverables.
- `cmd.generate-handoff` (command) — Generate HANDOFF.md from current verified state.
- `governing.claude-md` (governing) — Repository-wide Claude operating rules.
- `governing.company-os-md` (governing) — Company structure and routing model.
- `governing.project-truth-md` (governing) — Verified current project state only.
- `governing.status-md` (governing) — Implementation and validation status.
- `governing.roadmap-md` (governing) — Deferred and future work.
- `governing.handoff-md` (governing) — Continuation instructions.
- `governing.security-policy-md` (governing) — Secrets, permissions, supply-chain policy.
- `governing.changelog-md` (governing) — Material environment changes.
- `reference.capability-registry` (reference) — Machine-readable inventory of all capabilities.
- `reference.source-registry` (reference) — Inventory of external sources and decisions.
