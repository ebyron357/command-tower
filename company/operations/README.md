# Operations Department

Capabilities owned by this department:

- `skill.sop-creation` (skill) — Create SOPs with steps, owners, and failure handling.
- `skill.workflow-design` (skill) — Design workflows with queues, SLAs, and interfaces.
- `skill.project-management` (skill) — Plan projects with milestones, risks, and status cadence.
- `skill.process-improvement` (skill) — Improve processes with waste analysis and pilots.
- `skill.vendor-evaluation` (skill) — Evaluate vendors with requirements, risks, and TCO.
- `skill.incident-management` (skill) — Run incident process with roles, comms, and postmortems.
- `skill.handoff-management` (skill) — Create operational handoffs with ownership and open risks.
- `skill.knowledge-management` (skill) — Design knowledge systems and retention practices.
- `agent.operations-manager` (subagent) — Own SOPs, workflows, incidents, and operational handoffs.
- `cmd.process-design` (command) — Design or improve an operational process/SOP.
