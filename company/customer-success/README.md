# Customer Success Department

Capabilities owned by this department:

- `skill.customer-onboarding` (skill) — Design customer onboarding journeys and success milestones.
- `skill.customer-health` (skill) — Assess customer health with signals, risks, plays.
- `skill.renewal-planning` (skill) — Plan renewals with value proof, risks, expansion options.
- `skill.cs-reporting` (skill) — Produce CS reports with retention, health, and actions.
- `agent.customer-success-manager` (subagent) — Own onboarding, health, renewal readiness, and CS reporting.
- `cmd.customer-health` (command) — Run customer health assessment workflow.
