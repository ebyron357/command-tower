# Human Resources Department

Capabilities owned by this department:

- `skill.role-design` (skill) — Design roles with outcomes, scope, and success signals.
- `skill.hiring-plans` (skill) — Create hiring plans with leveling and capacity rationale.
- `skill.interview-kits` (skill) — Build interview kits with scorecards and bias controls.
- `skill.employee-onboarding` (skill) — Design employee onboarding journeys and checklists.
- `skill.performance-frameworks` (skill) — Design performance frameworks with fair criteria.
